# oneclickstudio 🚀

**OneClick Studio (HivePostly Studio)** is an all-in-one content creation, multi-track video editing, and social media cross-publishing powerhouse.

## ✨ Key Features

- **🎬 Video & Reel Editor**:
  - Full-featured canvas with multi-track timeline (video, audio, text, stickers, overlay).
  - Dedicated standalone editing tab with hardware-accelerated rendering.
  - Custom Themes: True Jet Black & Electric Light Blue modes.
  - **🚀 Direct Post to Composer Bridge**: 1-click bridge passing rendered clips via IndexedDB directly into the composer.

- **📢 8 Social Networks Direct Publishing**:
  - Full multi-network composer supporting simultaneous manual & batch selection:
    1. **Instagram** (Reels, Carousels, Stories, Feed)
    2. **Facebook** (Pages & Groups)
    3. **YouTube** (Shorts & Videos)
    4. **TikTok** (Sound sync & auto-captions)
    5. **Twitter / X** (Threads & Video tweets)
    6. **Threads** (Direct API integration & text-video cards)
    7. **LinkedIn** (Professional posts & carousels)
    8. **Pinterest** (Idea Pins, standard pins & board routing)

- **📱 Live Mobile Device Simulator**:
  - Real-time preview of video posts on simulated smartphone screens across various platforms.

- **🤖 AI Viral Flow Studio**:
  - Script generator, hook enhancer, thumbnail designer, and viral scoring engine.

- **⚙️ Account Connection Guides**:
  - Step-by-step guides for connecting all 8 platforms via direct handle linking or official OAuth Graph APIs.

## 🛠️ Tech Stack

- **React 18** with **TypeScript**
- **Vite** with HMR
- **Tailwind CSS** + **Lucide Icons**
- **IndexedDB** for zero-latency local video bridging
- **Canvas / WebCodecs API** for timeline video processing

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` to explore the studio!
